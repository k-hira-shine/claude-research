# Claude Computer Use — PC を操作する AI

最終更新: 2026-04-23
出典: Anthropic 公式・PCMag・MindStudio・Substack 複数記事

---

## サマリー

Claude Computer Use は「AI がマウスとキーボードを使ってPCを操作する」機能。
2024年10月に Claude 3.5 Sonnet で初実装（公開ベータ）。視覚的にスクリーンを認識して操作するため、API を持たない古いソフトウェアも自動化できる。

---

## 仕組み（ビジョン・アクションループ）★★★★★

出典: Anthropic 公式発表

```
スクリーンショット撮影
    ↓
画面の状態を視覚的に分析
    ↓
次のアクションを決定（クリック・入力・スクロール）
    ↓
アクションを実行
    ↓
（繰り返し）スクリーンショット撮影 → 結果確認
```

Claude が「見る」→「考える」→「操作する」を自律的に繰り返す。

---

## できること ★★★★★

| 操作 | 内容 |
|------|------|
| **マウス操作** | 移動・クリック・ドラッグ |
| **キーボード操作** | テキスト入力・ショートカット（Cmd+Tab 等） |
| **スクロール** | ページ内の上下スクロール |
| **ブラウザ操作** | URL へのアクセス・フォーム入力・リンクのクリック |
| **アプリ間の連携** | PDF → スプレッドシート → メール添付 などの横断操作 |

### 具体的なユースケース

**1. ソフトウェアテスト・QA** ★★★★☆
- Web アプリの視覚的バグ（レイアウト崩れ・壊れた UI）を自動検出
- 事前定義セレクタ不要でビジュアルテストが可能

**2. レガシーシステムの自動化** ★★★★☆
- API を持たない古いソフトウェア・SaaS ツールの GUI 操作を自動化
- 多段階フォームへの記入・ポータルへのログイン・データ抽出

**3. クロスアプリワークフロー** ★★★★☆
- 「PDF からデータをコピー → Excel に貼付 → メールに添付」を一気通貫

**4. ビジュアルデバッグ** ★★★★☆
- 開発サーバーを起動 → ブラウザで表示確認 → 見た目の問題を特定して修正提案

**5. Dispatch（モバイルから遠隔操作）** ★★★★★
- Claude モバイルアプリでタスクを指示 → Mac が自動実行 → 完了後に通知

## アクセス方法

| 経路 | 内容 |
|------|------|
| **Claude macOS アプリ** | "Cowork" / "Code" タブから使用可能 |
| **Claude Code CLI** | ターミナルから呼び出し、UI テスト・ワークフロー自動化 |
| **Dispatch** | モバイルアプリからタスクを遠隔で割り当て |
| **API（開発者向け）** | エージェントアプリへの組み込みが可能 |

---

## 限界・注意点 ★★★★★

| 制限 | 内容 |
|------|------|
| **速度** | 各ステップでスクリーンショット処理が必要なため API 自動化より遅い |
| **信頼性** | 動的コンテンツ・読み込み中の要素で誤操作が起きることがある |
| **視野** | 現在画面に表示されている要素のみ操作可能（スクロール外は見えない） |
| **セキュリティ** | システム操作権限を持つため、隔離環境での実行を Anthropic が推奨 |
| **対応 OS** | 2026年初頭時点では主に macOS（開発・テストは Linux 環境） |
