## 【前提】このフォルダの方針

視聴者が求めている答えは3つだけ：
1. **「私にも使えるの？」** → 使えます、こうすれば
2. **「何に使うの？」** → こんな場面で、こう変わります
3. **「ChatGPT と何が違うの？」** → 目的によって使い分けます

すべての動画ネタはこの3つのいずれかに答えるものを選ぶ。

## 1. 無料プランでどこまでできるか ★★★★☆

出典: AIonX・gamsgo・aiproductivitycoach 複数記事

### 無料プランの実態

| 項目 | Free | Pro（$20/月・約3,000円） |
|------|------|------------------------|
| メッセージ数 | 15〜40通 / 5時間ウィンドウ | その約5倍（45通以上） |
| 使えるモデル | Sonnet 4.5、Haiku 4.5 | Opus 4.5 含む全モデル |
| Claude Code | ❌ | ✅ |
| Projects（記憶機能） | 限定的 | 無制限・永続 |
| 優先アクセス | なし | あり（混雑時でも使える） |
| 学習への利用 | される可能性あり | されない（デフォルト） |

### 無料プランが向いている人

- 「まず試してみたい」入門者
- 1日数回しか使わない人
- 軽い文章チェックや調べもの程度

### Pro プランが向いている人（$20/月）

- 仕事や勉強で毎日使いたい
- 長い書類・資料を頻繁に読み込む
- Claude Code でコードを書きたい
- 混雑時でも止まらず使いたい

### 無料で使う上での注意

- **制限はメッセージ数ではなくトークン数（文字量）で決まる**
- 長い資料を貼ると一気に減る
- 会話が長くなると履歴の再処理で消費が増える
- 使用量を見るダッシュボードはない（「Claude Counter」という拡張機能が便利）

### ▶ 動画企画案

**「Claude 無料でどこまで使える？正直に全部教える」**
- Pro が必要な人・不要な人を明確に分ける
- 「3,000円の価値があるか」という視聴者の疑問に正直に答える
- 信憑性: ★★★★☆

## 2. 日常生活での具体的な使い方（主婦・学生向け）★★★★☆

出典: Yahoo Tech・Sikhadenge・Reddit r/claude 複数

### 主婦・家事での使い方

| シーン | Claude への頼み方 | 効果 |
|-------|----------------|------|
| **献立作り** | 「冷蔵庫に○○と○○があります。今週5日分の夕食の献立を作って。一品30分以内で作れるもの」 | 毎週の献立考える時間がゼロに |
| **買い物リスト** | 「この献立の食材を、スーパーの売り場順に並べて」 | 店内をウロウロしなくなる |
| **子どもの勉強サポート** | 「小学3年生にわかるように、都道府県の覚え方を教えて」 | 親が教えられない教科も対応 |
| **保護者会の案内文** | 「PTA 総会の案内文を、柔らかい丁寧な文体で書いて。日時は○月○日」 | 文章を考える時間が激減 |
| **クレーム対応メール** | 「このお客さんのクレームに対する丁寧な謝罪文を書いて。事情は〇〇」 | 気が重いメールが数分で完成 |

### 学生での使い方

| シーン | Claude への頼み方 | 効果 |
|-------|----------------|------|
| **レポート構成** | 「○○についての大学レポートの構成案を作って。2000字くらい」 | 「何から書けばいいか」がなくなる |
| **難しい概念の理解** | 「マクロ経済学の GDP を中学生にわかるように説明して」 | 教科書を読み直す前にまず聞く |
| **英語の添削** | 「この英作文を添削して。どこが変かも教えて」 | 先生に聞かなくても修正できる |
| **就活のエントリーシート** | 「この経験をもとに、志望動機を300字で書いて」 | 何度でも改稿してもらえる |
| **試験勉強** | 「この範囲を問題形式で10問出して。回答と解説もつけて」 | 過去問がない範囲でも演習できる |

### 一般会社員での使い方

| シーン | 効果 |
|-------|------|
| **会議の議事録 → 要点まとめ** | 録音テキストを貼るだけで整理完了 |
| **企画書の骨格作り** | アイデアを箇条書きで渡すと構成に直してくれる |
| **上司へのメール** | 「もっと丁寧に」「簡潔に」と言うだけで調整 |
| **調査資料のまとめ** | PDF を渡して「3行で要点を教えて」 |
| **SNS 投稿文** | 「この内容を Twitter 用に140字で書いて」 |

### ▶ 動画企画案

**「主婦が Claude を1週間使ってみたら家事が○時間減った」**
- 実際に試して体験談として語る形式
- 「難しそう」という先入観を壊す
- 信憑性: ★★★☆☆（個人体験談ベース。実際に試して語ることで★5になる）

## 3. 初心者でも使えるプロンプトの型 ★★★★★

出典: AI Prompt Library・promptbuilder.cc・note.com（日本語ガイド）

### 最も簡単な基本型（3つだけ覚える）

```
① 役割を与える
「あなたは○○の専門家です」

② やってほしいことを言う
「〜を〜してください」

③ 条件を付け加える
「○○字以内で」「初心者にわかるように」「箇条書きで」
```

### そのままコピペできるテンプレート

**メール作成**
```
あなたはビジネスメールの専門家です。
以下の状況に合わせて、丁寧なメールを書いてください。
・送る相手: [取引先の○○さん]
・目的: [打ち合わせの日程変更をお願いする]
・変更理由: [急な社内会議が入った]
・希望日程: [来週中のどこか]
200字以内でお願いします。
```

**資料の要約**
```
以下の文章を読んで、ポイントを3つにまとめてください。
専門知識がない人でもわかる言葉で書いてください。
[ここに文章を貼る]
```

**アイデア出し**
```
[○○]についてのアイデアを10個出してください。
対象は[30代の主婦]で、[コストをかけずにできる]ものに限定してください。
```

**勉強・理解**
```
[難しい言葉や概念]を、[小学生/中学生/初心者]にわかるように説明してください。
例えを使って説明してください。
```

### Claude ならではのコツ（初心者向け）

| コツ | 説明 |
|------|------|
| **「〜しないで」が通じる** | 「専門用語を使わないで」「箇条書きにしないで」など否定形の指示が正確に通る |
| **何度でも修正依頼できる** | 「もっと短く」「もっと柔らかい表現で」と後から言うだけ |
| **「なぜ？」を聞ける** | Claude は理由を説明してくれる。ChatGPT より詳しく教えてくれると評価多数 |
| **資料を貼ってから指示** | 長い文書を最初に貼って、「これを読んだ上で〜してください」が有効 |

### ▶ 動画企画案

**「これだけ覚えれば十分！Claude に何でも頼めるプロンプトの型3選」**
- 画面に型を大きく表示しながら実演
- 視聴者がそのままコピペして使える形式
- 信憑性: ★★★★★（公式ドキュメント・複数ガイドで一致）

## 4. ChatGPT vs Claude — 初心者が知るべき使い分け ★★★★☆

出典: ZDNET・Zapier・MoneyForward・note 日本語記事 複数

### 一言で言うと

> **「最初の一手は ChatGPT、文章を仕上げるなら Claude」**

### タスク別の使い分け（初心者向け）

| やりたいこと | オススメ | 理由 |
|------------|---------|------|
| 画像を生成したい | **ChatGPT** | DALL-E 統合あり、Claude は画像生成不可 |
| 声で話しかけたい | **ChatGPT** | 音声モードが優秀 |
| たくさんのアイデアを出したい | **ChatGPT** | 発散的・多様なアイデアが得意 |
| 文章を自然に書いてほしい | **Claude** | 人間らしいリズムの文体 |
| 長い資料を読んでまとめてほしい | **Claude** | 1M トークンで大量の文書を処理 |
| 正直なフィードバックがほしい | **Claude** | 「それは違います」と言える |
| メールや文書の最終仕上げ | **Claude** | 修正指示に正確に従う |
| 調べ物・ニュース検索 | **どちらも可** | 両方 Web 検索対応 |

### 無料プランの使い勝手比較

| | ChatGPT Free | Claude Free |
|-|-------------|-------------|
| 制限のゆるさ | ゆるい（GPT-4o mini を無制限で使える） | 少し厳しい（15〜40通/5時間） |
| モデルの質 | 中程度（GPT-4o mini） | 中程度（Sonnet 4.5） |
| 画像生成 | △（制限あり） | なし |
| **初心者への結論** | **最初はこちらから始める** | **文章系に慣れたら移行** |

### 日本人ユーザーの声

> 「ChatGPT は最初の壁を越えやすい。Claude は使い続けるほど良さがわかる」

> 「ChatGPT は"すごいな"と思う。Claude は"頼りになる"と感じる」

### ▶ 動画企画案

**「ChatGPT と Claude、正直どっちを使えばいいか全部教えます」**
- 目的別に「これは ChatGPT」「これは Claude」を明確に整理
- 「どっちに課金すべきか」という答えも出す
- 信憑性: ★★★★☆（複数の比較記事・ユーザー評価から）
